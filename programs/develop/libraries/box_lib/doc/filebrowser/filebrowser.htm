Структура FileBrowser

Введение

FileBrowser, используется при выборе файлов в программах: OpenDialog, Kfm.

Функции

FileBrowser_draw

Рисование FileBrowser, параметры перерисовки задаются в переменной fb_all_redraw.

FileBrowser_mouse

Эта функция должна вызыватся при движении мышей в FileBrowser.

FileBrowser_key

Выполнение действий по нажатию клавиш. Перед вызовом функции в переменной fb_key_action должно передаваться одно из следующих значений:

; 1 - arrow down
; 2 - arrow up
; 3 - PageDown
; 4 - PageUp
; 5 - Home
; 6 - End
; 7 - Enter
; 8 - Insert (выделение файла)
; 9 - Ctrl+A выделить все файлы
; 10 - отменить выделение файлов
; 11 - обратить выделение файлов
; 12 - поиск по букве

version_FileBrowser

Версия элемента

fb_type - тип элемента, если:

  • 0 - открыть,
  • 1 - сохранить,
  • 2 - выбрать директорию.

fb_size_x - ширина элемента (без скроллинга).

fb_start_x - отступ слева (положение по x).

fb_size_y - высота элемента.

fb_start_y - отступ сверху (положение по y).

fb_icon_size_y - высота иконки.

fb_icon_size_x - ширина иконки.

fb_line_size_y - высота линии.

fb_type_size_x - ширина колонки с типом файлов (зарезервировано, пока не используется).

fb_size_size_x - ширина колонки с размером файлов (зарезервировано, пока не используется).

fb_date_size_x - ширина колонки с датой файлов (зарезервировано, пока не используется).

fb_attributes_size_x - ширина колонки с атрибутами файлов (зарезервировано, пока не используется).

fb_icon_raw_area - данные для отображения иконок.

fb_resolution_raw - колличество бит на пиксель в данных для отображения иконок.

fb_background_color - цвет фона.

fb_select_color - цвет курсора.

fb_select_flag - 0,1.

fb_max_panel_line - максимальное число строк в окне.

fb_select_panel_counter - 0 - панель не в фокусе, 1 - панель в фокусе.

fb_folder_block - количество блоков данных входа каталога (БДВК).

fb_start_draw_line - номер первого отображаемого в окне файла или папки (номерация начинается с 0).

fb_start_draw_cursor_line - позиция курсора для выбора файла или папки (координата y в пикселях относительно fb_start_y).

fb_folder_data - буфер с информацией о файлах.

fb_type_table - указатель на память для заполнения строки с типом, размером и датой файла.

fb_ini_file_start - начало данных с расширениями и номерами иконок, получаемых из *.ini файла. Пример формата данных:

<dir>=0\n
<up>=1\n
<dic>=3\n
<doc>=3\n
...
src=61\n
vox=74\0

fb_ini_file_end - начало данных с расширениями и номерами иконок, получаемых из *.ini файла.

fb_draw_scroll_bar- параметр необходимости обновления дочернего скроллинга:

  • 0 - дочерний скроллинг обновлять не нужно,
  • 1 - изменилась позиция fb_start_draw_line и нужно обновить дочерний скроллинг.

fb_mouse_keys_delta - 0,1,2,3.

fb_all_redraw - параметр для функции FileBrowser_draw, задает параметры перерисовки: 0 - текст, 1 - все окно, 2 - иконки с текстом.

fb_key_action - код клавиатурного события для функции FileBrowser_key, возможные значения 0...12.

fb_draw_panel_selection_flag - внутренняя переменная, определяет с каким фоном будет рисоваться текст (fb_background_color или fb_select_color).
